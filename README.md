# Pronunciation Lab

Lesson 1〜10の310語・表現を練習する、iPad向けの静的ウェブアプリです。
Other words、Lesson 5のMfuwe Village、Lesson 8のGrand Banks・Newfoundlandは収録していません。

## 操作

- 右上の「▶ 使い方 30秒」から字幕付きの操作動画を再生できます。名前・組・番号の設定、練習、チャレンジ、認定証の提出まで紹介。動画は手動再生・インライン再生に対応し、閉じると停止します。
- 上部のLessonタブでレッスンを選択。最後に選んだレッスンを次回も開きます。初回はLesson 7。
- 教材の見出しに合わせ、Lesson 1・4・7・10はオレンジ、2・5・8は紫、3・6・9は緑。タブ選択で画面全体のテーマを切り替えます。
- 通常練習はPart・並べ替え・意味の非表示に対応。「すべて」はページ分割せず全語を表示。
- 全単語の自己ベストが90点以上になったレッスンに「単語」の王冠、発音スプリントの自己ベストが100点になったレッスンに「100」の王冠を表示。タブと進捗欄に表示し、保存済み記録にも適用します。
- 通常練習の新しい得点はカード中央に大きく揺れて現れ、約2.6秒後に消えます。直近5回の履歴は残り、動きを減らす設定にも対応します。
- お手本音声、マイクでの練習、直近5回の得点（60 → 75形式）、認識テキストの小文字表示。
- 発音スプリント：選んだレッスンから重複なしの10語。60秒以内は再挑戦可能。各単語の最高点を合計して100点満点。100点に達した時点で自動終了し、認定証を表示します。
- 日→英ワードラッシュ：選んだレッスン全体をシャッフル。日本語を見て英語で回答。正解で次へ。「skip」と発音するかボタンでスキップ。60秒または全問終了で結果表示。
- 各チャレンジの準備画面・結果画面の「得点履歴」から、日時付きの直近50回と直近5回の得点推移を確認できます。モード・レッスン別に保存します。ワードラッシュの各回の履歴はこの機能追加後から保存し、以前の自己ベストは保持します。
- マイクテストはiPad・PCともに入力音量のバー。3秒カウントダウン後にチャレンジ開始。
- 正解演出、名前・組番号・レッスン・実施日時（日本時間）入りの認定証。提出用の拡大表示に対応。
- 右上で名前・組（1〜13）・番号（1〜50）を設定。名前は全レッスン共通。

## 記録

得点履歴、練習回数、2つのベストスコア、苦手語はレッスン別にブラウザ内へ保存します。
従来のLesson 7用キーと単語IDを保持するため、同じURLでの既存記録は引き継ぎます。
レッスン切替時は進行中の回答をキャンセルし、古い結果を別レッスンへ保存しません。
リセットは選択レッスンの記録だけを消し、名前と他レッスンの記録を残します。
別端末・別ブラウザ・別URLとは同期しません。SitesからGitHub Pagesへの移動でも過去の記録は自動移行されません。

## 起動・検証

Node.jsの追加パッケージは不要です。

```sh
npm start
npm test
```

ローカルは http://localhost:4173 で開きます。iPadではHTTPSの公開URLを使ってください。
テストでは教材のPart区分・語数・音声ファイル、Lesson 7の旧記録、レッスン間の記録分離、各レッスンでの出題・終了・認定証、マイクの状態管理を確認しています。
iPad実機での連続音声認識と50人同時利用は未検証です。

## レッスンの追加

`dist/lessons.js`の`vocabulary`へレッスン番号をキーにした配列を追加します。
各行は `[英語, 日本語, 品詞, Part番号, 読み上げ用英語（省略可）]`。
タブ、Partの語数、出題範囲、結果表示は自動で追従します。
その後、macOSで `node scripts/generate-audio.mjs` を実行し、新しいお手本音声を生成します。
既存の音声は上書きしません。単語IDは記録・音声と対応するため、既存配列は並べ替えずに更新してください。

## 音声認識・採点

Web Speech APIで認識された文字と教材の英語を比較します。音素やアクセントの厳密な発音評価ではありません。
大小文字・空白・記号を無視し、教材外の同義語は正解にならない場合があります。
省略記号（…、～）は読みません。複数の語順を示す表現は1項目として、たとえば「throw away」を読みます。
お手本は同梱したPCM音声をWeb Audioで再生し、iPadのSpeechSynthesisとの切替を避けます。
iPadでは音声認識の接続を維持し、回答する単語を切り替えます。音量テストと認識接続は同時に使いません。
ブラウザや端末の設定、認識サービス、通信環境の影響を受けます。
音声をアプリ独自のサーバーへ保存しませんが、ブラウザの認識サービスで処理される場合があります。

## ファビコン

トップのplマークと同じアイコンを設定。32pxのPNGはテーマ色に連動し、iPadホーム画面向けに180pxのアイコンも同梱しています。

## 公開

GitHub Pages用リポジトリにはアプリ・音声・検証用コードだけを含めます。
教材PDF、Sitesの設定、ローカルのスクリーンショット、個人の練習記録は含めません。
`dist/`を静的配信するため、リポジトリ配下のURLにも対応する相対パスを使用しています。

Lesson 8〜10を追加済み（28・29・36語）。Lesson 8の品詞は日本語に統一し、Other wordsは除外。練習画面の並べ替えは未練習を先頭に、BEST得点が低い順。同点は教材順を維持し、もう一度押すと教材順へ戻ります。カード移動はアニメーション表示し、動きを減らす設定を尊重します。

iPadで再接続後に発話検出が返らない実機ログが確認されたため、発話ごとの接続更新を取り消し、接続を維持する方式に戻しました。OSが接続を終了する場合は影響を回避できないため、実機確認が必要です。

## 互換認識モードと入力表示

画面上部の「互換モード」スイッチで直接オン・オフできます。初回のオンで認識データを準備し、準備中もスイッチをオフへ戻せます。標準のWeb Speech認識が使えないiPad版Chrome、アプリ内ブラウザ、ホーム画面版向けの代替です。Safariの通常タブは既存の継続接続方式を既定のまま維持します。方式の選択はブラウザの開き方別に保存します。

互換モードはVoskの小型英語モデルを端末のWeb Worker内で実行します。音声を認識用サーバーへ送りません。初回はモデル約41MBとライブラリを取得（画面上は約45MB）。以降はVoskのIndexedDBキャッシュを使いますが、ブラウザの保存容量やデータ削除の影響を受けます。1端末あたり数百MB程度の実行メモリが必要で、実機性能・アプリ側のマイク許可に依存します。50台利用の同時認識サーバー枠はありませんが、初回データ転送は台数分発生します。Chrome・ロイロ・ホーム画面版のiPad実機では未検証です。

練習のマイク左には、互換モードでは同じ入力ストリームから測定した波形、標準モードでは音声認識の実イベントに応じた色の変化を表示します。「待機」などの状態文字は表示しません（読み上げ用ラベルは維持）。標準iPadではgetUserMediaを追加起動しません。実測していない疑似波形は表示しません。互換モードの単語認識結果にも既存の文字一致採点を使用し、厳密な音素評価ではありません。

依存ライブラリ・モデルの表記は `dist/vendor/NOTICE.txt`、Apache 2.0とMITのライセンスは同じフォルダにあります。モデルは公式ZIPの内容を変更せずtar.gzへ詰め替えています。

両モードで採点式は同一です。異なる音声認識エンジンが出力した文字に対して文字一致度を計算するため、同じ発音でも認識結果と得点は変わります。互換モードが音素を厳密に採点するわけではありません。

互換モードは各レッスンの全単語・表現とskipを認識候補に渡します。現在表示中の正解1語だけを候補にする方式ではありません。範囲外の発話を逃がす[unk]も含めます。microplastic等の連結語は同じ綴りになる分かち書きも候補に含め、認識された単語の前後に付く[unk]記号を文字一致の計算から除きます。認識候補は小さな文字データなので、約45MBのモデルの更新・再取得は不要です。モデル辞書外の語や発音差は引き続き認識に限界があり、音素評価の精度を保証する変更ではありません。

保存済みモデルは同じブラウザのIndexedDBから読み込み、展開完了マーカーがあればダウンロードを省略します。別ブラウザ・プライベート閲覧・閲覧データ削除・OSによる保存領域解放では再取得になる場合があります。アプリ全体をオフラインで開けることを保証する仕組みではありません。

## 音素チェック実験

`phoneme-lab.html` にサングラス・ミリメートルの独立した試作ページがあります。hama-js 1.7.0の音素ASRで、音声から直接得た音素と米音の目標音素を比べます。追加約5MB、端末内推論、合成音声の英語／カタカナ比較と4秒のマイク録音に対応。参考値は通常練習・チャレンジへ保存しません。英語音声にも認識ミスが残るため、正式採点へはまだ統合していません。実機・実声・騒音下での検証が必要です。方法と初期検証の限界は `experiments/phoneme-lab.md` に記録しています。
